The inner planets

Pick a planet. Each card's planet and name share a view-transition-name with the big versions on the planet's own page, so they morph from one page to the next. On a planet page, the previous and next links slide the page sideways instead. Try the browser's Back button too.

What makes this work

  1. @view-transition { navigation: auto; } in styles.css, which every page loads. Both the old and the new page must opt in.
  2. Matching names on both pages, for example view-transition-name: orb-mars on the card above and on the big Mars.
  3. view-transition-name: site-header keeps the header still while the page changes under it.
  4. The pageswap (old page) and pagereveal (new page) listeners in transitions.js add a type: drill-in, drill-out, forwards or backwards. The CSS selects animations with :active-view-transition-type().
  5. <link rel="expect" href="#main-content" blocking="render"> holds the new page's first frame until <main> has been parsed, so the new snapshot is complete.

Cross-document transitions only run for same-origin navigations. Chrome also runs them for pages opened straight from disk, but serving the folder over HTTP is the dependable way to try them (see the README).
